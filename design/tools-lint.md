# Tools: size, duplicates, dead code, splits and doc edits

Status: protocol  
Read when: running a size, dupe, dead-code, split, relocate or doc-edit tool  

Door, rules, the CLI contract and the Surf / A key: `tools.md`. Bot flows: the Bot job files; doc edit detail: `doc-library.md`.

Entries here: `lint.py`, `check.py`, `docs.py`; their code: `tools/lib/checks/`, `tools/lib/docs/`, `tools/lib/lint/`. `lint.py dupes` helpers: `tools/lib/lint/dupes_clone.py` (run / clone finder), `tools/lib/lint/dupes_gate.py` (gate, exceptions, selftest). `lint.py unused` helpers: `tools/lib/lint/unused_graph.py` (roots, per-file edges, categories, apply verification), `tools/lib/lint/unused_chunk.py` (`--paths` view, reach tags, baseline, plan block), `tools/lib/lint/unused_docfix.py` (exact stale-doc fixes), `tools/lib/lint/unused_selftest.py` + `tools/lib/lint/unused_selftest_chunk.py` (fixtures), hold list `tools/data/unused_hold.json`.

## Jobs

- **Script sizes:** `check.py script-cap --bot --sweep` (Bot; `--verbose` for every row). Doc sizes: `check.py docs-size --bot --boot --dupes`.
- **Duplicates:** `lint.py dupes` (summary first; `--out-md PATH` for the ranked list); the Bot gate is `lint.py dupes --gate` (run by `bot_status.py --bot --prove`).
- **Dead code:** `lint.py unused --limit 30` (report only). One chunk: `lint.py unused --paths GLOBS --save-baseline F`, `--why [FILE:]FUNC` for a row's edge path, then `check.py chunk-finish --paths GLOBS --baseline F [--plan-out P --chunk N]`.
- **Split a script:** `lint.py split FILE --list`, write `plan.json`, `lint.py split FILE --plan plan.json --dry-run`, then without `--dry-run`.
- **Move a cluster:** `lint.py move --list-cluster FACADE`, then `--to-dir DIR --dry-run`.
- **Host pitfalls (advisory):** `lint.py hostify`. Blank lines: `lint.py blanks PATH --dry-run`.
- **Doc edits:** `docs.py patch replace FILE --old A --new B`, `ensure-line FILE --line L`, `replace-file FILE --from-file NEW`, `changelog --bullet "..."`, `apply plan.json`.

After `--apply`: `gate.py gd-load` / bot smokes, then commit. Inner classes are their own scope: their bodies are roots, their funcs/vars are never candidates and never resolve to outer names; `--apply` refuses names also declared in an inner class, `@tool`/addon scripts and multi-line declarations. Limits: dataflow (a value computed but not wired, e.g. a perf readout) is not analysed. `--selftest`: fixture repos in temp roots.
