## Other seams

- `dirty-clear`: Clear one hard or soft flag: `store.clear_flag(repo, id, kind, reason)` or `pipeline clear ID --hard|--soft REASON --json` returning `{subject}`. Seam: `Backend.clear_flag`.
- `soft-dirty-clear`: Clear the soft flags a regenerate acknowledged: the same call with `--soft --all`. Seam: `Backend.clear_soft`.
- `export-bypass`: Export with hard flags held: `pipeline export ID --bypass-hard` returning `{path, sections, bypassed:[reasons]}`. Seam: `Backend.export_check`.
- `safe-cancel`: Stop a model job at a safe point without killing a pid: a cancel file or `pipeline cancel JOB` that calls `stop_comfyui`. Seam: `Backend._cli cancel`.
- `model-lock`: `pipeline lock --json` returning `{family, holder, since}` so a CLI run and the studio share one model slot, and a `stop_comfyui` hook. Seam: `Api.start_job busy check`.
- `step-locks`: Adopt the studio's step rules in the CLI: `pipeline step ID STEP --finish|--reopen`; actions and section saves need every earlier step Done (a group opens together) and their own step open; a step is Done only when its needs below are met; export needs every step Done and the bypass skips neither gate. Record keys: `studio.steps`, `studio.approvals {path: {state, view, step}}` (state also `hidden`). Seam: `Backend.require_open, Backend.set_step, Backend.export_check`.
- `step-overrides`: `generate`, `tune`, `smooth`, `body`, `edit` read `studio.overrides[step]` (prompt, negative, seed, strength, steps, width, height) or take the same flags, and echo what they used. Seam: `Backend.check_overrides`.
- `artifacts`: Every command lists what it wrote in `RESULT`/`--json` with the step: `{stills:[], glbs:[], clips:[], sounds:[], review, step}`. Seam: `Backend._cli`.
- `review-latest`: `pipeline review-latest ID --json` returning `[{path, image, role, verdict, checks}]`. Seam: `Backend.reviews`.
- `json-lists`: `--json` on `pipeline list`, `show`, `status`, and `coverage`. Seam: `Backend.list_subjects`.
- `export-sections`: Export maps section fields into the contract: `stats`, `dialog`, `audio`, `rules`, `paperdoll`, and `frames`/`sheets` from packed clips; today they are written empty and the fields ride under `sections`. Seam: `store.export_subject`.
- `vfx-attach`: The game places an effect at the chosen attach point (feet, aimed point, projectile tip, target, and planned hand and weapon tip). Today effects spawn at a world position with no attach-point table, and hand and weapon tip have no code path yet. Seam: `scripts/combat/player_hit/hit_atk.gd _spawn_fx`.
