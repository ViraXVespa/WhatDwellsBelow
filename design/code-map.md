# Live code map

Status: index 
Read when: you need a live script or scene for a named system

Game code only (tools: `design/tools.md` and its siblings). Open **only the matching system row**, not the rest of the table. When Grok Bot splits a live script, update this file in the same slice.

Each facade sits beside its cluster folder (`scripts/<area>/<stem>.gd` + `<stem>/`, refactor.md). A bare `name.gd` in a row is a helper in that folder; basenames are unique repo-wide, so `docs.py code-map row --path <full path>` and `find.py xref` find it. Facades keep the original public path; helpers take `host` / `pt` / `ui` / `p`.

A row named after a `design/routes.yaml` door is that door's code, and the same file set is that door's group in `gdhealth.toml` (`python tools/release.py graphs`). Rows with other names have no group.
