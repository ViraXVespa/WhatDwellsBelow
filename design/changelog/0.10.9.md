## 0.10.9

- Tools: screenshots can be read locally with Tesseract, with confidence, estimated letter height, contrast and expected-text matching. Shot flows can check known labels without a vision call.
- Tools: isolated screenshot reviewers now receive crop, zoom, image-difference and OCR helpers plus the available full-size source images. Text questions try local OCR first; visual reviews stay available without OCR. Failed or unavailable OCR is recorded so a reviewer can fall back honestly, and an explicit exception is kept in the review summary.
- Tools: the text-review hook now runs inside staged reviews instead of skipping them. Attempts expire after 30 minutes and are tied to image contents; no guessed OCR tool names or host permission bypasses. Media runners receive the same helpers and available originals without changing their generation permissions.

- Tools: split the performance-sweep runner into smaller rendering, journey and scoring helpers without changing the benchmark. Fixed the split tool to retain signal callback delegates and mark unused host parameters.

- Tools: split hitch-row formatting, timing and output into small helpers, retaining the existing log state and row contents.

- Refactor: moved actor light placement and slot updates into smaller helpers, keeping the same shading calculations and public API.

- Tools: split hitch-log session and tick handling into smaller files, keeping the existing counters, state and log lifecycle.

- Refactor: moved sole-image scanning into a small sibling helper without changing the scan or baked table format.

- Tools: the benchmarks share their repeated setup, visibility sampling, percentile and report routines. Hitch timing fields use one ordered table; the reported values, rounding and report text stay the same.

- Docs: corrected the Debug source map and replaced a dead example image path with an instruction to use the actual temporary file.

- Tools: long status summaries now stay within the console budget while retaining the source failure result. Full details remain in the log and with `--verbose`.

Summary: Local screenshot text checks and better-equipped isolated image reviews.
