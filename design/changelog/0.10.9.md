## 0.10.9

- Tools: `shots.py ocr` reads on-screen text with local Tesseract and rates it READ ok/weak/fail (confidence, x-height at 1080p, contrast; `--expect` match). `shots.py review --ocr` passes that text to the reviewer, and shot-flow `shot` steps can assert a label with `"ocr"`. Text checks no longer need a vision read.
- Tools: the repo pretool hook now asks for a local `shots.py ocr` run before an LLM OCR tool or a text-reading `shots.py review` (`--ocr` or `--why` passes); its own commit so it can be reverted alone.
