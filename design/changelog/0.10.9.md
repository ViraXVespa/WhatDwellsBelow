## 0.10.9

- Tools: screenshots can be read locally with Tesseract, with confidence, estimated letter height, contrast and expected-text matching. Shot flows can check known labels without a vision call.
- Tools: isolated screenshot reviewers now receive crop, zoom, image-difference and OCR helpers plus the available full-size source images. Text questions try local OCR first; visual reviews stay available without OCR. Failed or unavailable OCR is recorded so a reviewer can fall back honestly, and an explicit exception is kept in the review summary.
- Tools: the text-review hook now runs inside staged reviews instead of skipping them. Attempts expire after 30 minutes and are tied to image contents; no guessed OCR tool names or host permission bypasses. Local helper permissions reject shell substitution and redirection, including inside output filenames. The portable helper reuses the existing RESULT formatter, and the JSON hook has a separate hook entry. Media runners receive the same helpers and available originals without changing their generation permissions.

- Tools: split the performance-sweep runner into smaller rendering, journey and scoring helpers without changing the benchmark. Fixed the split tool to retain signal callback delegates and mark unused host parameters.

- Tools: split hitch-row formatting, timing and output into small helpers, retaining the existing log state and row contents.

- Refactor: moved actor light placement and slot updates into smaller helpers, keeping the same shading calculations and public API.

- Tools: split hitch-log session and tick handling into smaller files, keeping the existing counters, state and log lifecycle.

- Refactor: moved sole-image scanning into a small sibling helper without changing the scan or baked table format.

- Tools: the benchmarks share their repeated setup, visibility sampling, percentile and report routines. Hitch timing fields use one ordered table; the reported values, rounding and report text stay the same.

- Docs: corrected the Debug source map and replaced a dead example image path with an instruction to use the actual temporary file.

- Tools: long status summaries now stay within the console budget while retaining the source failure result. Full details remain in the log and with the documented `--verbose` option; a selftest checks both views.

- Clips: portrait montages crop each segment before drawing callout/title chips, keep end cards at native size and centre chip titles on tall canvases, including 4:5. Export/fit/montage accept focus/track/box fill with source boxes; chip placement keeps clear of its subject. Named movie regions stay scoped to the selected movie on each segment; tests cover all three fill modes and centred 4:5 title pixels. Tracking and image resizing keep their existing helper owners.

- Clips: tracked callout labels no longer avoid their own previous frame or flicker between slots. Distinct owners, half-open windows, sticky slots, a short safe hold, eased movement and edge clamping keep labels steady and separate.

- Tools: loading-bar traces now close their local server socket/thread and browser on failed imports, setup or runs, and remove console listeners on navigation errors. Failure-injection tests exercise the cleanup without launching a browser or game.

- Docs: reconciled the busy-fight repeat with the existing continuous perf sweep, checked current main and the subsequent shader/event-driven/HUD changes, and retired the stale standalone repeat. Historical scores are not current-code acceptance; the remaining desktop/two-cold-web evidence gap stays explicit, without substitute software-renderer scores or duplicate runs.

- Relay: prepared the supported structured email binding, escaped HTML/plain-text sender and acceptance/error handling, with generated-type, mock outbox and upload-free build checks. Mail stays off with no chosen sender or deployment. Arbitrary-recipient sending needs Workers Paid and conflicts with the relay's free-only decision; activation is blocked pending an owner decision and service/domain verification.

- Clips: comparison wipes now keep clean-source recipes. Native portrait/4:5 reconstructs both clean legs before drawing BEFORE/AFTER identity chips, keeps those chips inside the canvas, reserves their space and draws identity last so even a crowded callout cannot cover it. Legacy baked clips accept explicit recipes instead of guessed source/timing; regression tests use baked comparison inputs, trims and multi-segment exports.
