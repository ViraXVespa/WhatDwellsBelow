## 0.5.30

- Playtester (debug tool only): it now waits for the dungeon to be ready (no pause, load, menu or enter/wake transition) before sending input, runs at normal speed by default (the up-to-6x speed is now behind its own `--wdb-pt-fast` flag and only applies while it acts, never during loads), and ends a run that can never start as `stalled` instead of hanging. The run time limit counts acting time, not load time.
- Playtester cost: its per-frame decision work is about 40% cheaper (shared per-frame world snapshot, no repeated group scans or repeat A* for the same target) with identical choices; the journal is off on web; decision cost, gate time, unstick count and time scale are recorded per run and shown by `web_perf.py`.
- Playtester behaviour: reaction delay, small aim wobble, steadier strafing and a dodge after a hard hit, all drawn from a run-seeded generator so a seed still replays; fixed an error on clerks without a `used` flag and the AI timers that ran about 7x too slowly.
- New `--wdb-playtest-live-smoke` flag runs one live AI run headless and prints the result; opt-in `--wdb-pt-repeat` (URL `?wdb-pt-repeat`) makes enemy and crit rolls repeat for a seed (default runs stay random).

Summary: Debug-only playtester reliability and speed work. Nothing in the game changed: look, gameplay, audio and values are the same.
