## 0.11.2

- New read-only repo MCP for Grok Build, `wdb` (`lookup`, `check`, `protocol`): thin wrappers over the existing find/check/docs/session tools that answer with a status and a short first page, keep the rest behind a handle, and never re-send lines already shown in the session (reset after a compact).
- `slice.py open` now prepares the slice before Build starts: it runs `slice.py start` for the new session, lets a cheap gather agent refine the session plan, checks the result itself and writes `session-context.md`. A crash falls back to the plain seed with a loud warning; a halt or a failed check stops before launch. New `--review`, `--launch WT` and `--no-gather`.
- `session-plan.md` is now a context index (core items and conditional candidates) changed only through the new `slice.py adjust`, which logs every change and is replayed by `plan --refresh`; the new `slice.py expand` builds or validates the packet. `find.py func --full` prints a whole declaration.
- Build docs and skills point at the packet and the MCP instead of the manual trim; the live run with the real model is a separate step (task `build-gather-mcp`).

Summary: Behind-the-scenes Build tooling: slices open with their context already gathered and checked, and a repo MCP serves lookups in short, non-repeating pages, with no gameplay changes.
