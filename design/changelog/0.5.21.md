## 0.5.21

Gameplay and menus
- Gear: the Crit Damage affix now adds to the crit multiplier (hits on enemies and the training dummy), and the Movement Speed affix now speeds up the player. Both showed on gear but did nothing.
- Adrenaline: the XP stack is capped at `adrenaline_xp_max` (2.0, new tunable) and skill XP under adrenaline is no longer squared; the multiplier is applied once, in `add_run_xp`.
- Potion cooldown is 8 s with one home (`potion_cooldown` in `balance.gd`); potions carry no baked cooldown and `BAL_REV` 14 moves old saves to 8 s.
- Pausing (pause menu, inventory, other full-screen menus) also pauses the shrine buff timer, food healing, potion cooldown and the adrenaline window. Starting a new run fully ends adrenaline and clears the recent-kill list.
- Enemy flee is random per pack (seeded by the run seed, about 4 flee packs per floor) instead of always the first two; the damage threshold and the 2-per-floor cap are unchanged.
- Menus: Space (dash) no longer acts in menus (Enter, E and pad A still confirm); Backspace goes Back like Esc and B; the recap Back hint is gone; Enter, E and pad A on the title, splash and fullscreen gate press once instead of twice.
- Controls: one binding table (`scripts/input/binds/table.gd`) lists every action, defaults and rebindable pools. Every player action is rebindable, including Pause (Esc/Start), menu tabs, item tip and drop, and crystal zoom; sticks and `ui_*` menu navigation stay fixed. A swap that would leave the other action unbound is refused; swaps and refusals show a toast. Picking a slot waits for the next input with no timeout; a key that currently goes Back (Esc, Backspace, B, Start) asks to Confirm or Cancel before it binds, the other pool's Back key or a second click on the slot cancels, and sticks and `ui_*` stay fixed on purpose. Key hints in menus and toasts follow the current binds. Web keeps F1 as an extra pause.
- Crystal network map: Tab (Y on a pad) zooms the map. Trigger pulls turn one stats page at a time.
- Settings: Graphics has a Render scale row (Auto, 1.0, 0.8, 0.6; a fixed pick stops the dynamic scale) and Gameplay has a Language row (English only); both are saved.

Audio
- Second recordings for dash, hit, level and slam are picked at random with the original cue; the body hit layers under the hurt voice. One cue table (`FILES`) in `sfx.gd`; smoke 9 checks each path.

Web and performance
- The Placeholdia yard light is computed about 7x faster and read from the baked `hub_light` atlas, so the Title to Placeholdia load is almost 4 s shorter on a software-GL browser. Same pixels.
- Dungeon and hub music stream and load first; warm-up frames end early (capped at 6); a dynamic render scale lowers the 3D view in 0.1 steps (floor 0.6) when the frame rate stays under 40 fps (`DYNRES_*`, off with `--wdb-no-dynres` / `?wdb-no-dynres`).
- Web key prompts no longer log a display-server warning; audio exit leaks fixed; small per-frame script savings with identical output.

Localization
- Player-facing strings go through `tr()` with English as the default locale (`scripts/data/locale/en.po`, registered in `project.godot`); data tables translate by id. English text is identical.
- Saved items keep a name key and a `forged` flag, and the name is derived through `tr()`; item descriptions derive from the item ids the same way and the ghost shop stock holds ids only, so both follow the language; old saves migrate on load. Boss titles carry role ids (`gate_master`, `guardian`). The HUD prompt colour reads a `prompt_locked` flag, not text.
- Code-side English fallbacks are gone where `en.po` covers the key. The chosen language is saved with the other preferences and shown in the Language row. Plurals use `LocS.plural` and PO plural forms (two sites). Fonts and right-to-left are planned in `localization.md`, not built.

Debug, tools and docs (no player-visible change)
- Debug menu Values grouped into 27 categories; playtester waits for the dungeon, runs at normal speed by default and replays by seed; shot tool gains scripted flows, dungeon flows, `--full-map` stitched floors and repeatability knobs; `web_perf.py` flows.
- New shot flows: ambush groups for floors 1-4, named versus normal elites, and a lineup of all twelve enemies. `bible_prompt.py --enemy ID` prints the enemy bible prompt (prop, hand and idle pose table lives in the tool). The enemy bible is trimmed and gains an idle-prop rule: held props are drawn at rest so they can be animated later. Prompt glyph and world-pass tools share one font and a `!` glyph.
- Scripts moved into cluster folders, about 280 dead items and duplicated code removed, single sources for rosters, defaults, sfx cues, base size and tool constants, tunables drift fixed (unused keys removed; old saves load unchanged), warnscan findings cleared.
- Tools follow one CLI contract with new checks (`check_tool_docs --stale-refs`, `check_shot_gaps`, `check_script_cap --sweep`); docs trimmed, drift-audited, history wording rewritten as current state, new `localization.md` and `art-bible-enemy.md`.

Summary: Crit Damage and Movement Speed gear work, adrenaline XP is no longer squared, potions cool down 8 s, every action is rebindable, Render scale and Language rows, pausing stops buff timers, flee is random, menu input fixes, faster web hub load, and strings ready for translation (English unchanged).
