## 0.5.21

Gameplay and menus
- Gear: the Crit Damage affix now adds to the crit multiplier (hits on enemies and the training dummy), and the Movement Speed affix now speeds up the player. Both showed on gear but did nothing.
- Pausing (pause menu, inventory, other full-screen menus) now also pauses the shrine buff timer, food healing, potion cooldown and the adrenaline window. Starting a new run fully ends adrenaline and clears the recent-kill list.
- Enemy flee is random per pack (seeded by the run seed, about 4 flee packs per floor) instead of always the first two; the damage threshold and the 2-per-floor cap are unchanged.
- Menus: Space (dash) no longer acts in menus (Enter, E and pad A still confirm); Backspace goes Back like Esc and B; the recap Back hint is gone; Enter, E and pad A on the title, splash and fullscreen gate press once instead of twice.
- Controls rebinding: picking a slot waits for the next input (the page used to reset at once); Esc or Start cancels. Stats paging and tabs follow rebinding.
- Crystal network map: Tab (Y on a pad) zooms the map. Trigger pulls turn one stats page at a time.

Web and performance
- The Placeholdia yard light is computed about 7x faster and read from the baked `hub_light` atlas, so the Title to Placeholdia load is almost 4 s shorter on a software-GL browser. Same pixels.
- Dungeon music streams and loads first; warm-up frames end early (capped at 6); a dynamic render scale lowers the 3D view in 0.1 steps (floor 0.6) when the frame rate stays under 40 fps (`DYNRES_*`, off with `--wdb-no-dynres` / `?wdb-no-dynres`).
- Web key prompts no longer log a display-server warning; audio exit leaks fixed; small per-frame script savings with identical output.

Localization
- Player-facing strings go through `tr()` with English as the default locale (`scripts/data/locale/en.po`, 646 keys, registered in `project.godot`); data tables translate by id. English text is identical.

Debug, tools and docs (no player-visible change)
- Debug menu Values grouped into 27 categories; playtester waits for the dungeon, runs at normal speed by default and replays by seed; shot tool gains scripted flows, dungeon flows, `--full-map` stitched floors and repeatability knobs; `web_perf.py` flows.
- Scripts moved into cluster folders, about 280 dead items and duplicated code removed, single sources for rosters, defaults and tool constants, tunables drift fixed (unused keys removed; old saves load unchanged), warnscan findings cleared.
- Tools follow one CLI contract with new checks (`check_tool_docs --stale-refs`, `check_shot_gaps`, `check_script_cap --sweep`); docs trimmed, drift-audited, history wording rewritten as current state, new `localization.md` and `art-bible-enemy.md`.

Summary: Crit Damage and Movement Speed gear work, pausing stops buff timers, flee is random, menu and rebinding input fixes, faster web hub load, and strings ready for translation (English unchanged).
