## 0.5.38

- Menus: Space (dash) no longer does anything in menus. Godot's built-in confirm used to press the focused button on Space; it is now removed (Enter, E, and pad A still confirm). Backspace now goes Back like Esc and B. The Back-on-dash shortcut is gone from the crystal, hub, and debug menus.
- Controls rebinding: picking a slot now actually waits for the next input (before, the page reset itself the moment you picked a slot, so nothing was ever captured). While waiting, Space, Backspace, B, `[`, `]`, LB, and RB bind like any other input and do not act as Back or tab. Esc or Start cancels, and the footer says so.
- Recap: the Back hint is gone (only confirm works there).
- Stats paging and menu tabs follow rebinding: the target-lock and interact binds page the gear stats on keyboard (Enter still confirms), special and attack on pad, and tabs use the tab actions only.
- Title, splash, and fullscreen gate: Enter, E, and pad A pressed the focused button twice (once on press, once on release). They now press it once, on press.

Summary: Input fixes from the input sweep decisions. Look, gameplay, audio, and values are the same.
