## 0.12.0

- Dungeon map is event-driven. The floor map is built once and fog is revealed with a mask.
- Crystals and the player marker update on events instead of every floor tick.
- The corner minimap is a thin-ruled square that shows revealed terrain with fog on unrevealed cells.
- Settings → UI controls minimap size (25–1000 px), opacity, zoom (1×–256×, default 8×), and zoom mode (minimum or fixed).
- Settings → UI also holds full-map opacity and the map-toggle mode.
- Map toggle is a three-state control (hidden / mini / full) via the View/Back button or M key.
- Adaptive toggle (default) swaps between the full map and the saved rest state; cycle mode steps through all three.
- The full map opens fitted to the revealed area, supports zoom and pan, and gameplay continues underneath.
- HUD strip is tighter. Potion and food slots show the icon with stack count.
- Potion and food use a clockwise dark sweep for cooldowns and heal-over-time instead of a separate numeric bar.
- Player portrait shows progressive damage: bruises at 88 % HP, cuts at 72 %, and blood from 50 % downward.
- A red screen-edge glow appears at 50 % HP and intensifies toward 0 % (toggleable in Settings → UI, default on).
- Interact prompt has a dark plate so it stays readable over the dungeon.
- Campaign walker explores only the revealed floor and resumes cleanly after death or dispel.
- Campaign walker handles crystal binding, resource gathering, and gate seeking more consistently.
- Extraction-gate use by the campaign walker still needs more work.
- MCP is used when connected; gathering can be turned off with --no-gather.
- Gather agent and slice open/adjust behavior improved; local AI tuner updated.
- Tool efficiency, help probes, and pixel-shot handling on the GL SubViewport improved.

Summary: Week 12 ships a customizable event-driven dungeon map and minimap, clearer HUD damage feedback with portrait wounds and a low-HP border glow, a more reliable campaign walker, and improved build tooling.
