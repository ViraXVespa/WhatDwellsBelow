## 0.9.1

- Touch controls: in the hub only map, food, and potion stay dimmed and non-interactive; all other buttons are fully enabled. In the dungeon every button is fully enabled.
- Shots: new `--scheme pc|gamepad|touch` flag forces keyboard prompts, gamepad prompts, or the touch overlay for visual proofs.

Summary: Touch-pad buttons no longer appear disabled when usable; shot tool can force input scheme.
