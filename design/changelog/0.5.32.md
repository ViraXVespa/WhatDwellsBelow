## 0.5.32

- Crystal network map: Tab (the Y button on a pad) now zooms the map as the on-screen hint says. Before, the menu's focus navigation took Tab first and moved the highlighted item instead, so the zoom never ran.
- Menus that use the triggers for stat pages (inventory and forge): one trigger pull now turns one page. Before, each step of the analog pull counted as a new press and could skip several pages.

Summary: Input sweep of every screen against its on-screen prompts; two input bugs fixed. Look, gameplay, audio and values are the same.
