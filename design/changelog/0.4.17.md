## 0.4.17

- Centralize Autoload/flow `preload("res://...")` literals on facade owners (`app.gd`, `app_boot.gd`, `app_flow.gd`, `app_run.gd`, `app_set.gd`).
- Shared scripts and tunables live on `App` (plus `T`); boot-only `DebugS`/`AnimS` stay on `app_boot`; `LoadTiming`/`Anim` on `app_flow`; `UiText` on `app_set`.
- Cluster callers (`app_boot`, `app_run`, `app_set`, `boot`, `title`, `title_news`) use those consts — no `preload(variable)`, no load timing/path change.

Summary: One preload owner per Autoload/flow API; cluster files reuse App/facade consts.
