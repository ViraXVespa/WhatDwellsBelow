## 0.5.8

- Dungeon feel spec is occupancy-first: unused stone stays uncarved, extra loops need a 3-cell minimum hug gap (default 4), and angled packets stay seasoning.
- Ownership is one-way publish: gen writes hall runs, stream instances them, volume skins them, buffer mounts lights on interior faces. Outline bake is gen, not volume.
- Extra dungeon loops revert if they hug another hall closer than hall_hug_gap (default 4 unused cells, minimum 3).
- Dead-end stubs stop at that same clearance. hall_stub_count is tunable. Fillet and jag defaults are zero.
- Dungeon floors default to 128 rooms.
- Extra loops reroute through offset waypoints when a direct carve would hug; gen_extra_loops counts landed tunnels.
- Room placement spans the full floor interior so the south edge is no longer an unused stone belt.
- Outline spans come from room and hall shapes. Floor-wide missing-rim and hole-seal passes are gone.
- Fillet fallback is zero. Map smoke reports rim holes as info, not a pass gate.
- Wall mesh skips 1 m ortho faces when a chunk already has span ribbons.
- Stream collision uses ribbon boxes whenever wall runs exist.
- Web shots copy the PNG on an STA thread as image, PNG bytes, and a file drop so paste works in chat.
- Wall ribbons bevel at shared corners and plant a post instead of leaving an open cap.
- Removed wall-corner chamfers. Shared ribbon ends use a square column, not a bevel.

Summary: Lean dungeon-feel spec and one-way wall ownership.
