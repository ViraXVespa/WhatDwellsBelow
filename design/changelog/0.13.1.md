## 0.13.1

- Added a mobile-first LAN UI for the comfy-character workflow.
- UI is written for a non-technical user, starts automatically on port 8189, proxies ComfyUI, uses node 5/6 for positive/negative prompts, appends generated images, shows the prompt on the review screen with copy, disables Generate when empty, auto-scrolls to new images, supports clear marks (with confirm) and undo, includes a hideable session summary flyout, offers a best-effort Comfy start button, tappable status pill, soft haptic feedback, remembers More options state, clears the prompt on new session, persists form state, streams progress with a process-killing cancel, and writes the existing Good/Bad and Approve/Deny files.
- Fixed mobile UI workflow path to tools/data/comfy-character-workflow.json.
- Mobile UI now shows the real Comfy error when a prompt fails to queue.
- Mobile UI proxy now returns the real Comfy error body; failures are written to the Details log.
- Mobile UI shows a friendly status message again; real Comfy errors stay in the Details log. Clearer hint when the workflow file is missing or not API format.
- Mobile UI converts the UI-format character workflow to API format on the fly; original file is unchanged.

Summary: On-the-fly workflow conversion for mobile UI.
