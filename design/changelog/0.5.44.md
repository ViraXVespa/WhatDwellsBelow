## 0.5.44

- Gear: the Crit Damage affix now adds to the crit multiplier on hits to enemies and the training dummy (it was shown on gear and counted in the run stats but never changed the damage dealt). Base crit multiplier and gear values are unchanged.
- Pausing (pause menu, inventory, other full-screen menus) now also pauses the shrine buff timer, food healing, potion cooldown and the adrenaline window. Before, they kept running behind the menu, so a shrine or adrenaline could run out and food could finish healing while paused.
- Enemy flee is now random: each enemy pack rolls once (seeded by the run seed, so a seed replays) whether it is a flee pack, with about 4 flee packs expected per floor; the first two packs hurt no longer always flee. The damage threshold and the 2-per-floor cap are unchanged.
- Gear: the Movement Speed affix now speeds up the player (it showed on gear but did nothing; set bonuses already worked).
- Starting a new run now fully ends adrenaline (speed, XP stack and the loop sound) and clears the recent-kill list.

Summary: Bug sweep: Crit Damage and Movement Speed gear now work, flee is random per pack, and menus no longer burn buff, food and potion timers.
