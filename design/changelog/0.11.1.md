## 0.11.1

- Unused-code cleanup across all scripts: the unused-code sweep now follows the ways the game actually reaches its code (string calls on loaded scripts, lazy-loaded helpers, schema keys read by name, shot-flow targets, skin lists, typed facades), so far fewer live functions are flagged by mistake. Flagged "maybe unused" rows dropped from about 750 to 140; the rest are shared or debug-only paths that stay as warnings on purpose.
- Clearer types in playtest, debug menu, enemy AI, shop, pause/recap, music and light-stamp code (new `PlayHost`, `DebugMenu`, `EnemyHost`, `ProgressUI` class names) with no behavior change.
- Verified-dead code removed: the orphaned pause inventory action and text scripts (`inv_act.gd`, `inv_text.gd`) and their dead helper chain, the unused archives `rebuild`, unused dummy-boss helpers, and stale facades, with their doc mentions.
- Safer cleanup tooling: `lint.py unused` gains a per-chunk view (`--paths`, baselines, `--why` reach explanation), `--apply` removes exact stale doc references itself and records each pass, and visual-path deletions must pass a load check. New `check.py chunk-finish` runs a chunk's checks with one retry and prints the failing line.
- Fixes and coverage: the nightly promo clip selftest passes again on ffmpeg 6.1; the archives docs/read screens are covered by a shot flow; fresh worktrees are told how to install the Godot AI addon from the Asset Library.

Summary: Behind-the-scenes cleanup — the unused-code sweep now understands how the game reaches its code, dead inventory and debug leftovers are removed, and new tooling makes future cleanups safer, with no gameplay changes.
