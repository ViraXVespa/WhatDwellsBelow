## 0.8.0

- Quest board uses pinned posters. Pause gained a Quest tab between Inventory and Skills. Taking an offer lifts its poster into the tab; cancel or complete rolls new ones.
- Death recap uses the Skills journal layout: two paper sheets, XP columns and drain on the wide sheet, skill tip on the narrow one.
- Receptionist Talk and Ask? replace the old guild task list. Talk has a once-only first line then a rotating line; Ask? opens How-to-Play pages with baked screenshots.
- Crystal loadout and other code-drawn UI are moving to generated PNG art. New crystal frame work landed, UI style is locked in ui-style.md, mockups exist for the major screens, and isolated media has a generic UI kind.
- Receptionist redesign started: the bust is a clipped version of the existing sprite, with the young goth/metal guild-clerk design and NPC rekey recipe ready. Talk portraits can follow the same look.
- Ground wear is now a small baked tileable sheet sampled once, instead of a runtime hash. Web and desktop shade the same cells.
- Global rekey was rebuilt (clean plate, trimap, one alpha solve) and preserves pixel-art interiors past a glow-aware edge band. Tree, slot, vendor crate/pot, and arrow art were re-baked. Bibles were locked.
- Welcome banner text is restored and centered on the cloth via an overlay.
- Recap Continue button keeps its glyph and label as one group and dims correctly while XP drains. The footer chip is hidden.
- Gear tips step aside from open slot pickers so they no longer overlap the anvil. Pickers open beside their slot and stay on-screen. Camp HUD hides while camp menus are open. Vendor header shrinks to fit its board. Controls glyphs share one column.
- Ghost shop shelf rows have a thicker gold focus ring. Scroll cues appear on clipped lists. Crystal focus is gold (no pink). Updates shows player notes only. Title disabled buttons stay readable.
- Debug scripts stay out of release and web exports. Release smoke and the build gate run the stripped path. Root `_` folders are ignored; local exports go to `_out/web`.
- Hub performance benches record real frame time, layer capture, and measurable done-when criteria. Desktop-release timing tools were added. The ending-fill hitch on web remains under investigation.
- Isolated media tools gained aspect ratios, a real review gate, and NPC/UI kinds. Build-cycle docs, prove rules, unit queues, first-command path, and load-graph coverage were tightened.
- Size splits, leak fixes, dead-code drops, and export hygiene landed so the next week starts from a cleaner tree.

Summary: Week 8 Grok Build snapshot. Quest board and Skills-journal recap, UI PNG art and receptionist redesign underway, rebuilt rekey and baked ground wear, recap/gear/HUD polish, cleaner debug/release separation, hub perf tooling, and tighter build process.
