## 0.3.5
- Inventory (I / D-pad Right) only opens from gameplay. It no longer steals D-pad Right inside menus.
- Controls pool selector wraps Keyboard ↔ Gamepad. Stick X switches once per push; stick Y still moves the list.
- Reset Controls asks for confirmation, then restores that pool’s defaults instead of clearing binds.
- Pause tabs show a selected state. Confirm prompts show Select / Back and keep menu focus after cancel.
- Prompt glyphs follow the last used device immediately, including tab chips and gear stats paging (Q / E, not mouse).

Summary: Pause Controls and inventory shortcuts behave in menus, and on-screen glyphs stay in sync with the current input device.
