# Park: Build week session guide

Status: parked
Read when: resume parked build_week, week pins, gather/change/prove sessions


## Goal

A Grok Build week that does not put gather, change, prove, and close in one transcript. This park is the session guide. Implement protocol/docs in a later web pass; do not invent product systems.


## Shape

Not web Phase 1-7 copied into CLI.

Separate sessions (or new chats) for: gather / change / prove / close-out.

Pins are area checkpoints (law + one code-map row). Work happens on a fork or new session from that pin when the CLI allows. The CLI will not auto-fork; a week script may pass --fork-session.

Just-do inside one existing owner may be a real reshape, not an itty-bitty function. Stop-and-propose is for a new cross-system owner.

Prove is not the change session. After a red postcard, the next patch is a fresh session from the pin, not one more turn on the guilty transcript. Cap retries (two reds then stop). Skip remains a first-class word.


## Week skeleton

1. Quota resets.
2. User starts grok.
3. Week-start: worktree gc, lock file fresh, optional pin boot.
4. User works in those sessions.
5. Near 90% quota: week close.
6. Close-out: leave-off on disk, do not dump the week into the next turn.

Which named sessions exist (Bot-notes vs smoke vs slice) is still the User's pick at week start. This park does not freeze a 5-7 roster.
