## File writing rules
- When using write or edit tools, ALWAYS write the COMPLETE file content.
- NEVER omit any sections, functions, comments, or lines.
- NEVER use "omitted for brevity", "...", "rest of the file", summaries, or placeholders.
- Write every single line fully, even for large files.
- If a file is too large for one response, say so and write it in complete sequential chunks, but do not leave incomplete content.
