## 0.2.47
- Fullscreen prompt now works with a gamepad or keyboard, and closes on its own once the game is actually fullscreen
- Escape opens the pause menu on the web instead of leaving fullscreen
- Alt+Enter toggles fullscreen in the browser the same way Pause → System does
- New web builds should load without clearing the cache or using a private window
- Version numbers now go up once per update, matching the notes on this screen

Summary: Boot, web display, and update delivery so a couch player can get past the first screen and actually receive the build they just got.
