## 0.2.49
- F1 and Escape no longer open and immediately close the pause menu on the web
- Those keys keep working after the first press instead of locking until a refresh
- Pause → System now has Quit
- Alt+F4, Ctrl+W, and Ctrl+Q leave fullscreen and close the game window when the browser allows it

Summary: Fix the web pause keys, and give players a way out of fullscreen instead of trapping them in the tab.
