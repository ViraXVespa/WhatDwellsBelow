## 0.3.8
- Analyze no longer asks twice. Opening the list and picking a piece destroys it and writes the forge book.
- Salvage spare gear sits on Gameplay settings, off by default.
-- When it is on, Finish at least and Fortune at least decide which duplicate greens and blues stay in the bank. Miss both bars and the copy becomes smithing XP. New traits, a higher item level, or a luck roll that beats the book are never salvaged.
-- Whites still follow the starter path on extract.
- Forge can run 1–9 pieces in one job. Cost and wait scale with quantity. A bar shows the current piece.
-- Back stops the queue. Finished pieces go to a results screen. The unfinished piece is dropped. Materials already spent stay spent.
- Results use inventory icon cells. Held pieces start selected. Pick up to three. Confirm replaces only that type’s holds.
- Item level and quantity use the same horizontal stepper as the Floor Crystal floor picker.
- The kit card and live combat read affix rows only, so leftover range / crit / on-hit keys on old saves no longer apply.

Summary: The anvil now treats Analyze as a single pick, lets you batch-forge and choose holds on a results screen, and stops old gear keys from inflating combat or the stats card.
