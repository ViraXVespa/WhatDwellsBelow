## 0.3.4
- Live GitHub Pages export still ships even if a pinned archive fails to import or export.
- Frozen archive web builds are cached by pin id and commit so unchanged snapshots are not rebuilt on every push.
- Failed archive exports print Godot’s log instead of stopping at a Python traceback.

Summary: Pages no longer dies on one bad archive pin, and later deploys reuse cached snapshot builds.
